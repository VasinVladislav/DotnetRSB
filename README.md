# 🏦 BankApi (.NET Core Backend for Russian Standard Bank Clone)

Веб-API коммерческого интернет-банка, спроектированное по трехслойной архитектуре (Repository/Storage Pattern). Обеспечивает безопасную авторизацию, регистрацию клиентов, сессионный контроль и интеграцию с облачной базой данных **Supabase (PostgreSQL)**.

## 🚀 Ключевые фичи и технологии

- **Платформа:** `.NET 9.0 / .NET Core Web API`
- **СУБД:** `PostgreSQL` (развернута на облачной платформе **Supabase**)
- **ORM:** `Entity Framework Core` (Code-First подход с миграциями)
- **Безопасность:**
  - Криптографическое хэширование паролей с помощью алгоритма **BCrypt** (`BCrypt.Net-Next`).
  - Система сессий на основе **безличных GUID-токенов** (`SessionToken`) вместо передачи персональных данных в HTTP-запросах.
  - Защита от BOLA/IDOR уязвимостей на уровне эндпоинтов.
- **Архитектура:** Четкое разделение ответственности. Контроллеры (`Controllers`) отвечают строго за HTTP-протокол, а слой хранилища (`UserStorage`) инкапсулирует прямые запросы к контексту базы данных.

### 👥 Аутентификация и воронка входа

#### 1. Проверка и фиксация номера телефона
- **URL:** `POST /api/user/verify-phone`
- **Тело запроса:** `{ "phone": "+7 (999) 000-00-00" }`
- **Логика:** Если номера нет в базе, он фиксируется со статусом `PhoneVerified`, а фронтенд получает команду на перенаправление к анкете. Если номер активен — запрашивается пароль.

#### 2. Вход в интернет-банк
- **URL:** `POST /api/user/login`
- **Тело запроса:** `{ "phone": "...", "password": "..." }`
- **Ответ (Успех):** `{ "token": "GUID-сессии", "userName": "Имя" }`

#### 3. Регистрация нового профиля (Анкета)
- **URL:** `POST /api/user/register-profile`
- **Тело запроса:** `{ "phone", "password", "lastName", "firstName", "middleName", "hasNoMiddleName", "birthDate", "email" }`
- **Ответ (Успех):** Генерирует новый хэш BCrypt, записывает анкету в UTC-формате, открывает сессию и возвращает токен.

### ⚙️ Личный кабинет и Настройки (Безличные запросы)
*Все эндпоинты ниже требуют обязательного заголовка `Authorization: Bearer <token>`.*

#### 4. Получение данных профиля клиента
- **URL:** `GET /api/user/profile-info`
- **Логика:** Сервер считывает токен, находит пользователя и возвращает его анкетные данные (ФИО, дату рождения, почту).

#### 5. Изменение текущего пароля
- **URL:** `POST /api/user/change-password`
- **Тело запроса:** `{ "oldPassword": "...", "newPassword": "..." }`
- **Защита:** Проверяет старый пароль через BCrypt, блокирует установку нового пароля, если он совпадает со старым.

#### 6. Изменение электронной почты
- **URL:** `POST /api/user/change-email`
- **Тело запроса:** `{ "newEmail": "..." }`
